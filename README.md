# coldbase

Загрузка холодной базы из Excel в AmoCRM: проверка контактов в AmoCRM по выбранному полю (идентификатору), список исключений и создание лидов из остальных записей с настраиваемым маппингом и выбором воронки.

## Сборка и запуск

```powershell
cd D:\coldbase
npm install
npm run build
npm start
```

Режим разработки: `npm run dev`.

## Docker (деплой)

На сервере создайте `.env` (см. `.env.example`), затем:

```powershell
docker compose up -d --build
```

Приложение будет на порту 3000. Токен AmoCRM сохраняется в папке `./data` на хосте (volume). Для продакшена задайте в `.env`:

- `AMOCRM_REDIRECT_URI=https://ваш-домен/api/amo/callback`

Перезапуск: `docker compose up -d --build`. Остановка: `docker compose down`.

## Настройка AmoCRM

1. Создайте интеграцию в кабинете AmoCRM (client_id, client_secret, redirect_uri).
2. **Redirect URI** в настройках интеграции укажите тот же URL, что и в `.env` (например для продакшена: `https://ваш-домен/api/amo/callback`).
3. Скопируйте `.env.example` в `.env` и заполните переменные (в т.ч. `AMOCRM_REDIRECT_URI` для вашего окружения).
4. В браузере откройте приложение и перейдите по ссылке «Авторизация AmoCRM» — после входа токен сохранится в `data/amocrm-token.json`.

## Использование

1. Загрузите Excel-файл с холодной базой.
2. Выберите колонку-идентификатор (например телефон) и нажмите «Проверить в AmoCRM».
3. Просмотрите списки «Исключения» и «К добавлению».
4. Нажмите «Загрузить воронки и поля лида», выберите воронку и при необходимости статус, настройте маппинг колонок Excel → поля лида.
5. Нажмите «Загрузить в CRM».
